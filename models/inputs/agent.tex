Agent description:
    $x(t)$: current capital [rub]
    $c(t)$: spendings [rub]
    $r$: effective rate [1/year]
    $r= 0.5$: rate value
    $x(0) = 1000$: initial capital
    $\sigma$: spendings boundary coefficient [1]
    $\sigma = 1$: bound value
    $\frac{dx(t)}{dt} = r*(x(t)-c(t))$: capital dynamics
    $T$: planning horizon [year]
    $T = 1$: horizon value
    $\delta$: discount  [1/year]
    $\delta = 0.5$: discount value
    $\sigma*c(t)\leq x(t)$: spendings boundary
    $t$: time [year]
    $c(t) \geq 0$: no-overdraft conditions

Agent functional:
    $\MAX = 1/T * \int_0^T (\exp{-\delta*t} \ln(q*c(t)))dt$: functional
